## ✨ Features

- **Responsive Design:** Optimized for all screen sizes (mobile, tablet, and desktop).
- **Appointment Booking CTA:** Prominent call-to-action buttons for scheduling visits and emergency dental support.
- **Service Highlights:** Dedicated sections detailing family dental care, pediatric dentistry, and specialized treatments.
- **Fast Load Times:** Built with Vite for lightweight asset bundling and optimal performance.
- **Accessible UI:** Clean typography, high-contrast themes, and intuitive navigation.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React with TypeScript
- **Bundler & Dev Server:** Vite
- **Styling:** Tailwind CSS, `tw-animate-css`, `tailwind-merge`
- **Routing:** Wouter
- **Component Primitives & Modals:** Vaul
- **Validation:** Zod
- **Package Manager:** pnpm
- **Hosting & CI/CD:** Vercel
